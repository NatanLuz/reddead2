## 📖 Sobre o projeto

O **Red Dead Redemption 2 - Website** é uma aplicação web estática desenvolvida com HTML5, CSS3 e JavaScript, inspirada no jogo *Red Dead Redemption 2*.

O projeto demonstra práticas de desenvolvimento front-end relacionadas à construção de interfaces responsivas, organização visual, navegação entre seções, animações e experiência de uso em diferentes dispositivos.

A estrutura separa conteúdo, apresentação e comportamento: o HTML organiza as informações, o CSS controla o layout e a responsividade, e o JavaScript gerencia as interações da interface.

## ✨ Funcionalidades

### Conteúdo e navegação

- Menu de navegação fixo;
- rolagem suave entre as seções;
- menu hambúrguer animado para dispositivos móveis;
- seções sobre História, Personagens, Mundo, Missões e Trilha Sonora;
- integração com conteúdo externo do Spotify.

### Interface

- Layout responsivo para computadores, tablets e dispositivos móveis;
- animações durante a rolagem com AOS;
- efeitos de hover;
- transições suaves;
- ícones fornecidos pelo Font Awesome;
- organização visual voltada à navegação fluida.

## ⚙️ Como executar

### Pré-requisitos

- Git;
- navegador moderno, como Chrome, Edge ou Firefox.

O projeto não possui dependências para instalação nem exige processo de build.

### Clonar o repositório

```bash
git clone https://github.com/archivesysl/reddead2-project.git

cd reddead2-project
```

### Abrir localmente

Abra o arquivo principal em um navegador:

```text
index.html
```

### Executar com Live Server

Como alternativa para desenvolvimento:

1. Abra a pasta do projeto no Visual Studio Code;
2. instale a extensão Live Server, caso ainda não esteja disponível;
3. abra `index.html` com a opção **Open with Live Server**.

### Verificação funcional

1. Confirme o carregamento em desktop e dispositivos móveis;
2. teste a navegação entre as seções;
3. verifique o menu hambúrguer;
4. teste a interface em diferentes resoluções;
5. confirme a execução das animações durante a rolagem;
6. verifique os efeitos de hover e as transições.

## 📂 Estrutura do projeto

O projeto separa estrutura, estilos, comportamento e recursos visuais:

```text
reddead2-project/
├── index.html
├── style.css
├── animacao.js
├── assets/
│   └── imagens e ícones
└── README.md
```

- `index.html`: estrutura e conteúdo das seções;
- `style.css`: layout, responsividade, transições e efeitos;
- `animacao.js`: interações e animações da interface;
- `assets/`: imagens e ícones utilizados pelo website;
- `README.md`: documentação técnica.

## 🌐 Deploy

O projeto é um website estático e está preparado para publicação sem processo de build. Pode ser hospedado no GitHub Pages, Vercel, Netlify ou em qualquer servidor web estático.

Para publicar, basta disponibilizar os arquivos preservando a estrutura dos diretórios. A Vercel está incluída entre as tecnologias previstas para hospedagem, mas o README atual não registra uma URL pública específica.
